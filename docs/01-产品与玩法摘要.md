# 产品与玩法摘要（老板可读）

## 产品是什么
《这桌不能坐》：一桌宴席座位关系小游戏。少靠说明书，多靠表演看出谁和谁不能挨、要不要换座。

## 正式三关（冻结锚点）
灰盒三关：选座、关系约束、安心铃等。玩法包冻结，作为扩展锚点。  
内部备份：https://zhousong-xd.github.io/demo001/frozen/

## 表现线曾想做成什么样（已停方向的设计意图）
- 少字；表演说玩法
- 固定一桌；仇友短循环
- 凡动必有戏；人数戏；椅型也说话
- 可吵架、不管会升级、换座走路遇人
- 曾要求「小而搞」短反应（如仇人拒坐）

详细见同目录 `04-表现重设计说明.md`、`05-设计表.md`。
