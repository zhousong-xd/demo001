## 怎么看出玩法（少字）

1. **座位关系在演**：看着谁、背对谁，比文字规则更先到。
2. **好友短循环**：兔 ↔ 鹤会招手/点头；挨着有绿光。
3. **仇人短循环**：狐 ↔ 兔会别扭、互不看；挨着有红光/炸毛。
4. **你的活**：点角色再点空位（或另一只交换）——把仇人分开、把好友凑近。
5. **范围**：固定一桌；「老街」以后再加。

开局故意让狐挨兔（别扭）。点「换个座试试」可看好友挨近后的「成了」。
