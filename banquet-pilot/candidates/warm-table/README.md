# 暖绘本 · 狐兔饭局表现小样

2026-09-13。状态：可操作表现候选，不是正式新关卡，不替换冻结三关或线上遗留预览。

## 打开

直接打开本目录的 index.html。它是一个自包含 HTML：内联 SVG、CSS 和 JavaScript，无外部图片、字体、网络请求或依赖安装。声音默认关闭，不持久化进度。

本小样只做两个角色、四个座位、一枚安心铃，复用冻结产品 f28893f3c419d794c6ba102bac67038683cb462c 的规则与棋盘函数。场景抽取 at 和 not_faces_unless 两种现有规则，不修改正式 levels 或 dist。

## 怎么玩

- 狐坐窗边 A1；兔未安心时不能与狐正对面。
- 点兔，再点 B2；或把兔直接拖过去，就能以换座解题。
- 也可点安心铃再点兔：安心后可与狐对坐，库存由1变0。点狐不会扣库存。
- 先点已入座角色，再点另一位，可交换座位；回到候客区后入座，可顶替原客人。
- 撤销同时恢复座位、安心状态、库存和操作计数；重玩恢复初始局面。
- 支持 Tab/Enter 操作，Esc 取消选择。右上角可以开启声音或减少动画。

预览中的“可放”不等于规则满足。冲突座位仍能落下；不会偷偷拒绝合法的放置操作。

## 资源与动画

- guests.html：原创 SVG 分层资产。狐与兔各有身体、头、耳、尾、左右手、眼睛/眉/嘴和独立阴影。没有从旧效果图裁切角色或制作整图切帧。
- index.template.html：暖色房间、窗边标记、固定木椅、桌体、餐具、茶汽、交互控件。
- style.css：呼吸、眨眼、耳朵、尾巴、落座和短反应；系统减少动画设置优先，用户可切换。
- app.mjs：位置动画、鼠标/触摸/键盘输入、目标预演、撤销、单铃波纹、开席提示。少量音效由 Web Audio 合成，默认静音。
- model.mjs：薄状态层，只调用已存在的规则与道具函数，不另写一套胜负逻辑。

动作中断不会延迟模型提交；新的操作取消旧的有限时动画/定时器。拖拽时只做预览，放下才提交；pointercancel、第二指介入、失焦、尺寸变化取消当前拖拽。
