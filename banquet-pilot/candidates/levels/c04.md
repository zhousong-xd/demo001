## Learning goal

Reduce fixed-seat (`at`) anchors so the player feels they are **solving**, not filling a pre-labeled answer key. Accept that several legal arrangements may exist; settlement should treat all legal solutions as equivalent (see baseline §13 #04). Still only the six shipped rule kinds — **no new mechanics**.

## Seats / guests / rules sketch

**Layout:** `6` → seats `A1 A2 A3 B1 B2 B3`.

**Guests:** all six (`fox`, `rabbit`, `crane`, `otter`, `tanuki`, `hedgehog`).  
**Props:** none.

**Rules (existing six kinds only — this brief uses ≤3 kinds; fewer `at` than L01–L03):**

| Sketch ID | kind | subject | other / seat | Player-facing intent |

| C04-r1 | `at` | fox | seat A2 | 仅一席预约（中位锚，非角） |

- **Fewer fixed seats:** only **one** `at` (vs two in L01–L03 teaching slots). Remaining seats left to relational constraints.
- Design intentionally tolerates **multiple** legal solutions once enumerated — do not force uniqueness in this brief.
- `hedgehog` / `crane` may be lightly constrained or unconstrained fillers in a later JSON draft; this sketch keeps crane as same_row partner only.
- Kinds **not** used here: `end`, `not_faces_unless`.

**Geometry reminders (ruleVersion 0.1):** adjacent = same row & index ±1; faces = different row, same index; same_row = A with A / B with B.

## Tips outline (3 tiers)

1. 这一桌预约很少，多半要靠关系自己排。
2. 同排不等于紧挨；对面要隔桌同列。
3. 先放好唯一预约席，再试狸掌柜与白先生的同排，以及团团避开阿狐。
