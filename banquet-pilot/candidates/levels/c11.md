## Learning goal

**Multi-constraint, few anchors:** pack several relational rules so guests must “cooperate” into a satisfying table — but keep **few** (ideally **0–1**) hard `at` seats so the puzzle is inference, not fill-in-the-blank. Stay **one-screen readable**; do **not** expand to a second table or dozens of guests (baseline §13 #11 — *保持一屏可读，不扩到十几名客人*). Still only the six shipped rule kinds — **no new mechanics**.

## Seats / guests / rules sketch

**Layout:** `6` → seats `A1 A2 A3 B1 B2 B3` (same shipped geometry; no dual tables).

**Guests:** all six (`fox`, `rabbit`, `crane`, `otter`, `tanuki`, `hedgehog`) — **not** more.  
**Props:** none preferred (calm optional only if a later draft needs a soft conflict; prefer pure seating here).

**Rules (existing six kinds only — denser mix, ≤1 `at`):**

- **Few anchors:** at most one `at`; remaining pressure from `faces` / `same_row` / `not_beside` / `end` combinations.
- **Readable:** still six guests, six seats, one long table; relation lines should follow shipped “selected guest only” guidance — no new UI chrome.
- Contrast with C05/C06 (multiple ends / two face pairs): C11’s beat is **density of mixed kinds with sparse anchors**, not a single new noun.
- Kinds **not** required here: `not_faces_unless` (keep optional). No calm_bell in the preferred sketch.

**Geometry reminders:** adjacent ≠ faces; same_row allows not_beside to still fire; ends = index 1 and 3 on the six-seat table.

## Tips outline (3 tiers)

1. 这一桌预约很少，要靠好几条关系一起想。
2. 同排、对面、端位可以同时成立；先满足最硬的一条。
3. 若线缠在一起，试着先放端位与唯一锚，再配对对面。

(Aligned to #4 game-design baseline §13 #11 合作开席 — 多约束组合但少固定席；保持一屏可读，不扩到十几名客人.)
