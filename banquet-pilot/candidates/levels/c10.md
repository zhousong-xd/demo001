## Learning goal

Teach a **pre-entry story rule change**: opening copy / situation framing may change which of the six shipped kinds apply **before** the player places anyone — e.g. “上次约好对面聊天，这次闹了个小误会，先别坐对面.” The player still solves a **fixed** rule set for the whole seating phase. **Forbidden:** mutating win conditions or rewriting predicates after the player has already acted (baseline §13 #10 — *禁止玩家行动后突然改答案*). Still only the six shipped rule kinds — **no new mid-solve rewrite mechanic**.

## Seats / guests / rules sketch

**Layout:** `6` → seats `A1 A2 A3 B1 B2 B3`.

**Guests:** all six (`fox`, `rabbit`, `crane`, `otter`, `tanuki`, `hedgehog`).  
**Props:** none preferred (keep focus on story-framed rule mix; calm_bell only if a later draft proves needed — prefer **no** calm here).

**Rules (existing six kinds only — this brief uses ≤4 kinds; story picks the mix at entry):**

| Sketch ID | kind | subject | other / seat | Player-facing intent |
| --- | --- | --- | --- | --- |
| C10-r1 | `at` | crane | seat B2 | 轻锚：白先生仍约了中下席 |
| C10-r2 | `not_beside` | rabbit | other fox | 误会后：团团先别挨着阿狐 |
| C10-r3 | `faces` | otter | other crane | 阿獭仍想隔桌碰杯（不变） |
| C10-r4 | `same_row` | tanuki | other hedgehog | 狸掌柜与小刺同排张罗 |
| C10-r5 | `end` | hedgehog | — | 小刺要端位 |

- **Pre-entry only:** opening beat explains why this table’s mix differs from a remembered prior (e.g. C02-style faces for rabbit↔fox **does not** apply this time; `not_beside` does). Rules are authored once in data; story does not call a runtime “swap rule kinds” API.
- **Hard stop:** no post-move rule injection, no “surprise rewrite after first seat,” no new predicate for “story override.”
- Contrast with C03/C07 calm: those **exempt** a condition via shipped `calm` state; C10’s beat is narrative selection of the starting constraint set, not an in-play prop.
- Kinds **not** required here: `not_faces_unless` (optional later). No second prop / dual tables.

**Geometry reminders:** adjacent = same row & index ±1; faces = different row, same index; story text must not invent “nearby / beside” meanings outside ruleVersion 0.1.
