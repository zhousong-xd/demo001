## 一句话

**玩法绑死表演**：座位对不对，要靠「拿起—悬停—落下—挤开」每一步的戏看出来；规则条文尽量少，戏要满。

参考气质：《这个座位有人坐吗？》《Seat the Drama》《Good Evening!》——短循环、可读关系、好笑或有张力。

## 为什么重设计

前几版（T-053/055）已验证：少字 + 仇友短循环能懂。缺口是：

1. **移动过程戏不够**：换座常像「抬一下再放下」，功能感弱。  
2. **人数一变，群像没设计**：2 人桌和 5 人桌不应同一套动作。  
3. **丑关系缺意外**：仇人同桌只有别扭，缺少笑点/张力升级。  
4. **座椅不会说话**：人数/玩法/关系全靠角色，椅子只是灰板。

## 设计原则（老板可读）

| 原则 | 含义 | 不做 |
| --- | --- | --- |
| 凡动必有戏 | 拿起、悬停、落下、挤开，每步都有可见反馈 | 只做位移补间 |
| 关系先于说明书 | 好友/仇人用表情、朝向、节奏说清楚 | 堆规则条文 |
| 人数即舞台 | 2/3/4/5/全桌各有群像与互动密度 | 人数变了动作照抄 |
| 丑关系也好玩 | 仇人同桌要有意外笑点或张力 | 只会红光+别扭 |
| 规则先稳住 | 演满现有规矩（挨/不挨、指定座、安心等） | 本环不加复杂新规则 |
| 固定一桌 | 本版只出一桌小样 | 老街以后再加 |
| 椅型也说话 | 人数/玩法位/关系用不同椅子表达 | 所有座位同一张灰板 |

## 交互扩展（功能感）

每一种操作都要回答：**玩家看得出「发生了什么」吗？**

1. **拿起**：角色离席、影子留座、桌面空出来；本人进入「悬着」态（表情期待/警惕随关系变）。  
2. **悬停空位**：座位「请客」或「拒绝」的预演（光晕色、桌上小反应，不是说明书）。  
3. **悬停有人座**：预演交换或挤开——被指向者先有反应（点头 / 皱眉 / 躲开）。  
4. **落下**：入座落地戏 + 邻座连锁（好友招手、仇人别过脸）。  
5. **挤开**：被挤者夸张离席回候客（或飞回空位），短音效感用动画代替。
