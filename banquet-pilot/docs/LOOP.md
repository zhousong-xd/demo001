# Banquet 自闭环 · 像人做事（短页）

人类经秘书确认整版规则。**不打断进行中的环**；新条文从下一环起全面执行。

## 总原则（四条）

1. **自闭环**：做 → 验 → 精简总结 → 再做。玩法/工程/质检/美术/合并导入同一环，不另开流程活。  
2. **人类主看总结**：经宴席·秘书转发；有问题才纠偏；**无异议 = 继续**，不必事事等人。  
3. **总结要精简**：实质进展、风险、确需人类知道的决定；少黑话、不堆长交接。  
4. **冻结三关是锚点**：正式可玩包推进一切扩展；候选先验过再升正式。

## 锚点与边界

- 冻结产品 SHA：`f28893f3c419d794c6ba102bac67038683cb462c`（`banquet-pilot/dist/banquet-pilot.html`）  
- 未获明确放行：不改冻结 dist、不合并 PR、不把候选冒充正式关/正式美术  
- 真机/多指缺环境就写未测，不伪造

## 一环怎么走

做 → 验 → 精简总结 → 再做。

### 「一环做完」标准（B）

同时满足才算验过：

1. **可打开**（有明确打开方式）  
2. **可复现**（步骤/命令/证据路径）  
3. **有一行经验记录**（STATUS 或 Issue）

### 卡住升级（C）

同一问题 **两环仍过不了** → 必须写入半小时总结请人类看，**禁止空转**。

### 经验沉淀（D）

每环至少一条「有效 / 翻车」。定期（每日或每几环）收成短经验，避免只做不学。

### 候选升正式（E）

须 **独立质检 + 人类无异议（或总结里明示）** 再导入正式 levels/assets。作者自测 **不能** 代替独立验收。

### 纠偏时效（F）

秘书确认人类意见后 **立刻转** 主导；通常 **下一环** 落实，除非人类写明「立刻」。

## 「需人类知」门槛（A）

半小时总结 **必须** 写入的情况：

- 方向变了  
- 要动冻结包  
- 要合并 PR  
- 真机失败  
- 卡死超一环（见上 C）

其余默默继续，不刷人类。

## 各角色每环自检（五问）

派单/开工/收工前各过一遍：

1. **本环做什么？**（一个可验收结果）  
2. **怎么验？**（命令/打开方式/证据）  
3. **经验记什么？**（一行有效或翻车）  
4. **会不会堵别人？**（路径冲突、等谁、能否并行）  
5. **下一步是什么？**（下一环主人 + 一句话）

| 角色 | 额外注意 |
| --- | --- |
| 主导 demo001 | 只派单/验/收；不写业务代码 |
| 宴席·工程 | 只做 ASSIGN；不碰冻结 dist 除非 P0/P1 |
| 宴席·质检 | 默认只读；作者报告≠独立验收 |
| 宴席·美术 | 无 ASSIGN 不扩批量 |
| 宴席·秘书 | 只对接人类；转述要点不堆黑话 |

## 计划模板（一页短句）

- **当前主目标：** …  
- **后续几步：** 1) … 2) … 3) …  
- **中长期方向：** …（正式关扩展 / 美术定稿 / 合并 PR 等，择要）

## 半小时总结结构（固定五段）

1. 现状  
2. 本环结果  
3. 下一步  
4. 中长期  
5. 需人类知的风险（按门槛 A；可无）

经宴席·秘书转发；像人汇报，少黑话。
