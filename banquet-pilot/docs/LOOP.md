# Banquet 自闭环 · 像人做事（短页）

人类经秘书确认。**不打断进行中的环**；新规矩从下一环起全面执行。

## 一环怎么走

做 → 验 → 精简总结 → 再做。无异议 = 继续，不必事事等人。

## 各角色每环自检（五问）

派单/开工/收工前各过一遍：

1. **本环做什么？**（一个可验收结果）
2. **怎么验？**（命令/打开方式/证据）
3. **经验记什么？**（一行写入 STATUS 或 Issue）
4. **会不会堵别人？**（路径冲突、等谁、能否并行）
5. **下一步是什么？**（下一环主人 + 一句话）

| 角色 | 额外注意 |
| --- | --- |
| 主导 demo001 | 只派单/验/收；不写业务代码 |
| 宴席·工程 | 只做 ASSIGN；不碰冻结 dist 除非 P0/P1 |
| 宴席·质检 | 默认只读；作者报告≠独立验收 |
| 宴席·美术 | 无 ASSIGN 不扩批量 |
| 宴席·秘书 | 只对接人类；转述要点不堆黑话 |

## 计划模板（一页短句）

- **当前主目标：** …
- **后续几步：** 1) … 2) … 3) …
- **中长期方向：** …（如：正式关扩展 / 美术定稿 / 合并 PR，择要）

## 半小时总结结构（固定）

1. 现状  
2. 本环结果  
3. 下一步  
4. 中长期  
5. 需人类知的风险（可无）

经宴席·秘书转发；少黑话。
